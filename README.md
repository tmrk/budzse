# Büdzsé

A free, interactive exploration of Hungary's public finances from 2000 to 2027.

Explore government revenue, expenditure, deficits, GDP and official development assistance. Compare budgeted and actual figures, adjust historical values for inflation, and inspect the official source behind every number.

Available in Hungarian and English.

[Open Büdzsé](https://tmrk.github.io/budzse/)

## Data API

The figures can be read without the chart and without JavaScript. Start at the [API catalog](https://tmrk.github.io/budzse/api/v1/index.json). [llms.txt](https://tmrk.github.io/budzse/llms.txt) is a short map for agents. The guide is in [Hungarian](https://tmrk.github.io/budzse/hu/api/) and [English](https://tmrk.github.io/budzse/en/api/).

Each observation has a permanent URL. The stored money value is nominal. A budget, an outturn, a part-year figure and a forecast are different records. Cite the original publisher together with the Büdzsé URL.

## About this project

This is a personal project I made for myself, so that I can easily oversee and understand some of these numbers about my home country. It is not official, but all the sources are referenced.
